# ── macura-drone requirements ────────────────────────────────────────────────
# Targeted at Google Colab (Python 3.12, CUDA GPU). All deps below install
# cleanly on Colab's current runtime + numpy 2.x.

# Backbone note: we build on Stable-Baselines3 (maintained) for the SAC learner,

# --- core scientific stack -------------------------------------------------
# IMPORTANT: do NOT list numpy / scipy / torch here. Colab already ships a
# self-consistent, CUDA-matched build of these, and re-installing them is what
# corrupts the numpy/scipy ABI (e.g. "_blas_supports_fpe" / "dtype size
# changed"). We only install packages that are genuinely missing, and let pip
# leave the preinstalled scientific stack untouched. numpy consistency is
# repaired by setup_colab.sh step 4c.

pyyaml>=6.0

# against the reference paper's MuJoCo results). MuJoCo is the optional backend.
#
# NOTE: gym-pybullet-drones is NOT on PyPI — it is installed from GitHub source
# by setup_colab.sh (step 4b). Do NOT add it here or `pip install -r` aborts.
pybullet>=3.2              # PyBullet physics engine
